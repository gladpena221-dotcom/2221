head — службовий блок сторінки. Його вміст не відображається напряму на екрані, тут вказується кодування, налаштування вікна та заголовок вкладки браузера.

body — основна частина документа, де розміщується весь видимий контент: заголовки, текст, списки, зображення та посилання.

h1 — головний заголовок першого рівня, який відповідає за назву всієї сторінки.

a — тег для створення посилань. Адреса переходу задається всередині атрибута href.

img — тег для додавання зображення. Атрибут src вказує шлях до файлу або посилання на картинку, а alt містить текстовий опис зображення.
